# 客户端

本目录包含保险客户 H5、运营管理端的前端构建产物，以及用于提供静态页面和转发 API 请求的 Nginx 配置。当前副本提供可部署的前端文件，不包含完整的前端开发源码工程。

## 页面组成

- `bolee/insurance-app/`：客户侧 H5，包括保险产品浏览、投保相关页面、本人保单入口和 AI 客服页面。
- `bolee/insurance-mgt/`：运营管理端静态页面。
- `conf/`：Nginx 配置及其辅助配置文件。`nginx.local.conf` 将客户侧和管理端的 API 请求转发到对应 Gateway。
- `html/`、`contrib/`：Nginx 随附的默认页面和辅助文件。

## 运行依赖

- Nginx：托管 H5 和管理端静态资源，并反向代理 API 请求。
- Java 后端：需要相应的 Gateway、认证服务和保险业务服务处理 API 请求。
- AI 客服：需要 Java 侧 AI 接口、Python Agent 服务、AgentOS 数据库及已配置的模型服务。

前端能否完成登录、保险业务和 AI 对话，取决于对应的后端服务及其依赖是否可用。运行日志、临时文件、进程文件和本机密钥配置不属于客户端发布内容。
