# 保险客服 Agent 功能范围

> 当前实现说明（2026-11-22）：Python 已接入产品条款检索工具，Java 提供条款来源授权和结构化引用透传。实际运行仍依赖手工 PostgreSQL 迁移、分离数据库角色、OAuth/embedding 配置及前端 UI 渲染；未完成端到端验证前不视为可生产问答。

## 目标

为保险平台客户提供产品信息、产品比较与个人保单自助问答。Agent 负责理解自然语言、补充必要信息和解释结果；产品筛选、用户身份、保单数据及权限由 Java 业务服务负责。前端通过 Java 访问客服，不直接连接 Python Agent 或数据库。

## 功能规划

| 阶段 | 功能 | 数据来源与边界 |
| --- | --- | --- |
| 第一阶段 | 保险常见问题、产品介绍、保障责任与免责条款解释 | 仅使用已审核、在售产品资料和对应版本条款；回答应能指向资料来源。资料缺失或冲突时说明无法确认。 |
| 第一阶段 | 产品推荐与比较 | 对话收集客户主动表达的保障目标、预算等必要偏好；Java 产品服务按确定性规则筛选和排序，返回少量候选、匹配理由、关键差异及官方详情链接。客户自行打开详情并选择。 |
| 第二阶段 | 查询本人已购保单 | Java 从登录身份确定客户，仅返回本人有权查看的保单字段。可回答保费、缴费周期、保障期限、生效日期、保单状态、续保信息等；以保单系统的实时数据为准。 |
| 第二阶段 | 解释本人保单保障内容 | 根据保单对应的产品与条款版本解释责任、等待期、免责和理赔条件；区分“合同约定”与一般说明，不推断系统未提供的结论。 |
| 后续评估 | 理赔进度、办理材料、服务流程、转人工 | 只读查询先行；涉及提交、修改或确认业务时，转入已有正式流程并要求客户确认。 |

## 推荐与展示规则

- 推荐结果是供客户比较的候选项，不代表承保、核保结论或购买保证。
- 年龄、地区、预算等筛选条件只采用已审核的产品规则；不在客服对话中进行健康核保或收集非必要健康信息。
- 产品名称、条款要点、价格及链接必须来自 Java 产品服务或审核后的资料。未接入准确报价接口时，不估算具体保费。
- 前端以结构化候选数据渲染产品表格；Agent 可以解释差异，但不能自行增加产品、修改价格或生成未经验证的产品链接。
- 表格应突出客户关注的保障范围、主要限制、等待期或免责提示，并提供官方详情页链接。

## 数据与权限原则

- 客户请求先由 Java 完成登录认证；Python 不接受模型或客户端自行指定的客户身份。
- 查询个人保单时，Java 每次按已验证身份和授权范围检查数据归属，只向 Agent 返回回答所需的最少字段。
- 产品推荐优先使用客户在当前对话主动提供的偏好；个人保单信息仅在客户登录且有授权时读取。
- 会话、模型调用和业务查询应记录必要的审计信息；敏感字段应最小化传递，并按确定的保留期限处理。
- Agent 无法从已批准的数据源确认时，应明确说明并提供人工客服或正式业务入口，不得猜测。

## 明确不做

- 自动核保、承保判断、健康风险评估或承诺理赔结果。
- 自动投保、支付、退保、变更保单或提交理赔。
- 直接访问保险业务数据库、执行任意 SQL，或查询其他客户的资料。
- 编造产品责任、免责、保费、生效日期、等待期、投保资格或业务办理状态。

## 当前实现状态

当前实现状态（以 `full_with_agent` 分支代码为准）：

- **已打通基础聊天**：Java 客户 API 校验登录身份并调用 Python/Agno；Python 返回自然语言回答。
- **已打通只读产品目录工具**：Agno 可查询 Java 动态分类，并按客户明确选择的分类检索最多三项在售产品。Python 将经过校验的目录候选结构化返回 Java。该能力不是个性化推荐，也没有报价、匹配排序或确认过的产品详情页链接。
- **会话运行存储可用，但客户会话生命周期未闭环**：Agno 使用 PostgreSQL 保存运行会话并把最近运行加入上下文。Java 会话/轮次 DAO 与清理任务骨架尚未接入聊天调用；Python 私有历史读取和删除适配也未完成，因此不能视为 Java/Python 会话持久化、历史和删除链路已完成。
- **已具备代码、等待业务数据发布验证**：个性化产品推荐的 Java API、Python client/service、Agno 工具以及结构化结果收集和 Java 客户响应映射已连接；响应可透传产品版本、比较事实状态和目录/规则版本。真实候选依赖已审核发布的产品事实和规则；当前开发快照产品尚未完成备案版本映射与发布，不能声称真实业务数据已上线。产品详情页路由和报价仍未接入。
- **条款代码已接入，环境尚未启用**：Python 有 leased task worker、pgvector 索引/检索、证据约束回答与结构化引用；Java 有来源管理、OAuth 任务 API 和客户响应引用映射。仍需迁移 PostgreSQL schema、配置 OAuth/embedding、完成端到端验证和前端引用展示。扫描版 PDF OCR 尚未实现。
- **尚未接入**：正式报价、本人保单查询与条款解释、理赔查询及实际转人工流程。
